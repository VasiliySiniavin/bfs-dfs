# Сравнительный анализ BFS и DFS для нисходящего разбора в КС-грамматике

## Описание
Индивидуальное задание по курсу «Программное обеспечение систем искусственного интеллекта».  
Реализованы две стратегии неинформированного поиска: **поиск в ширину (BFS)** и **поиск в глубину (DFS)**.  
Задача — поиск вывода цепочки в контекстно-свободной грамматике (нисходящий разбор).

## Структура проекта
problem.py — класс GrammarProblem, формализующий задачу.
search_solver.py — абстрактный класс SearchSolver  (методы solve(), get_statistics(), reconstruct_path()), узел Node, базовая инструментация.
bfs.py — реализация BFS (в ширину).
dfs.py — реализация DFS (в глубину) с опциональным ограничением глубины.
main.py — набор из 5 тестов, запуск обеих стратегий, вывод пошагового лога и сводной таблицы.
